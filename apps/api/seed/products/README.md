# Sample product photos

Photos here are attached to the sample products of the same name. Put a photo here named after the product's id to give a sample product its picture
when the API starts (`SEED_ON_START=true`):

| File | Product |
| --- | --- |
| `white-ghutra.jpg` | Premium white ghutra |
| `red-shmagh.jpg` | Red & white shmagh |
| `black-agal.jpg` | Classic black agal |
| `leather-sandals.jpg` | Leather sandals |
| `oud-50.jpg` | Oud perfume 50 ml |
| `cufflinks.jpg` | Cufflink set |
| `sandals-embossed-brown.jpg` | Embossed brown sandals |
| `sandals-woven-burgundy.jpg` | Woven burgundy sandals |
| `sandals-beige-buckle.jpg` | Beige buckle sandals |
| `sandals-blue.jpg` | Blue leather sandals |
| `card-holder-black.jpg` | Leather card holder, black |
| `card-holder-lime.jpg` | Leather card holder, lime |
| `card-holder-red.jpg` | Leather card holder, red |

`.jpg`, `.jpeg`, `.png` and `.webp` all work. Use square photos, about 1000 × 1000 px and under 2 MB.

Each product gets its photo once, and only if it has none, so photos uploaded in the admin
are never replaced and a photo removed in the admin stays removed. To change a photo later,
use the admin (Catalogue > Products).
